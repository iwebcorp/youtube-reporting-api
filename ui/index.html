Custom ID 입력

Custom ID가 없거나 사용할 수 없는 값이어서 공란인 자산입니다. 입력한 값은 전달 파일의 공란에 바로 저장됩니다. 비워 둔 자산은 저장하지 않습니다.

Asset IDAsset Title공란 위치Custom ID

영문 Custom ID 수정

전달용 CSV에서 값이 하나이고 영문이 포함된 자산입니다. 기존 값을 확인한 뒤 새 Custom ID를 숫자로 입력해 주세요. 저장하면 표시된 파일의 해당 값이 바뀝니다. 비워 둔 자산은 유지됩니다.

수정값은 이번 달 전달 파일에만 적용됩니다. 3단계를 다시 추출하면 다시 입력해야 합니다.
